# 🏮 file-lantern

**Local file indexer & instant search for Windows.** Find any file by name or content in milliseconds — everything stays on your machine.

> Status: 🟡 Early scaffold. Docs & backlog in place; implementation starting issue-by-issue.

---

## Overview

file-lantern builds a fast local index of your drives and folders so you can search files the way you search the web: start typing and results appear instantly. It indexes **filenames** (like Everything) *and* **file contents** (full-text, like a mini desktop search engine), all offline.

An optional **local-AI mode** lets you ask natural-language questions — *"the invoice PDF from last spring"* or *"my python script about parsing CSV"* — resolved by a tiny local model, with **no cloud calls**.

## Motivation

Windows Search is slow, opaque, and cloud-tangled. Everything is fast but filename-only. Grep-style tools are powerful but not friendly. file-lantern aims for the sweet spot:

- **Instant** filename search across whole drives.
- **Full-text** content search for documents, code, and notes.
- **Private by default** — the index never leaves your PC; no account, no telemetry.
- **Optional AI** — natural-language queries via a tiny local model, never required.

## Use cases

- Locate a file you half-remember the name of, across all drives, in one keystroke stream.
- Find every document/code file containing a phrase, function name, or client name.
- Rediscover old notes and PDFs by describing them, not naming them (AI mode).
- Keep a lightweight, always-fresh index that updates as files change.

## How to use (Windows-first quickstart)

> Packaging is in progress; until the first release, run from source (see PLAN.md).

### Run from source (Windows 10/11)

Prerequisite: install the **.NET 8 SDK**.

```powershell
git clone https://github.com/rwrife/file-lantern.git
cd file-lantern
dotnet build FileLantern.sln
dotnet run --project src/FileLantern.App/FileLantern.App.csproj
```

Current milestone status: filename indexing, instant search-as-you-type, full-text content search, and structured query filters are wired in for the desktop app.

### Example workflow

```
budget            → filename matches for "budget"
content:refund    → files whose text contains "refund"
ext:md content:TODO   → markdown files containing "TODO"
size:>100mb ext:zip   → large archives
```

### Query syntax

You can combine plain filename terms with any of these filters:

- `ext:<value>` — extension filter (examples: `ext:pdf`, `ext:md`).
- `size:<op><value>` — size in bytes/kb/mb/gb/tb (examples: `size:>10mb`, `size:<=512kb`).
- `modified:<op><age>` — relative age (`s`, `m`, `h`, `d`, `w`) where `modified:<7d` means modified within the last 7 days and `modified:>7d` means older than 7 days.
- `content:<phrase>` — full-text phrase search against indexed file content. Use quotes for multi-word phrases, for example `content:"quarterly revenue"`.

All filters can be mixed with filename terms in a single query, for example:

- `invoice ext:pdf modified:<30d`
- `report ext:md content:TODO`
- `notes size:>1mb modified:>90d`

If a filter token is malformed, it is treated as plain text rather than crashing the search.

### Local-AI integration (optional)

file-lantern works fully without AI. When enabled, natural-language queries are
translated by a small local model into the same structured query syntax used by
the core engine (`ext:`, `size:`, `modified:`, `content:`).

- **Compatible backends:** [Ollama](https://ollama.com) or any
  [llama.cpp](https://github.com/ggml-org/llama.cpp) OpenAI-compatible server.
- **Suggested tiny models:** MiniCPM-family, Qwen2.5-1.5B/3B-Instruct,
  Llama-3.2-1B/3B, Phi-3-mini.
- **Fail-closed behavior:** if local-AI is disabled, unreachable, times out, or
  returns malformed JSON, search silently falls back to normal non-AI search.
- **Privacy guarantee:** local-AI requests are allowed only to loopback hosts
  (`localhost`, `127.0.0.1`, `::1`, `0.0.0.0`). Non-local endpoints are ignored.

Settings are stored at:

- `%LocalAppData%\\file-lantern\\settings.json`

Example:

```json
{
  "localAi": {
    "enabled": true,
    "endpointUrl": "http://localhost:11434",
    "model": "qwen2.5:1.5b-instruct",
    "timeoutSeconds": 3
  }
}
```
